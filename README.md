# Troubleshooting-Bot
This is a private and local RAG/Text-to-SQL chatbot made during my summer internship at Collins Aerospace, therefore none of the actual code was allowed to be published

<b>Project: TroubleshootingBot - Developed local, SQL-to-Text, and RAG chatbot for technician assistance.</b>

- Managed project timeline, data cleaning, SQL integration, and cloud deployment.
- Collected user feedback and made decisions based on their needs and expectations.
- Improved technician productivity by 15% for experienced users and 45% for novices. While
presenting product demonstrations to stakeholders, highlighting a potential $1 million in savings.
- Technologies used: Python, SQL, Plotly.js, Next.js, Flask, Ollama, Docker, DataBricks, VectorDB,
AWS.
